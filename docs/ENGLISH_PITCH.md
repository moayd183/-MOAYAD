# SkyShift AI — 90-second judge pitch

**What if anyone could watch the sky change — with real science, not just beautiful space imagery?**

SkyShift AI is an independent, Arabic-first astronomy explorer designed around NASA's SPHEREx mission. A learner enters the name of a star, a planet, or any celestial coordinates. Our server obtains positions from authoritative astronomy catalogs and queries NASA/IPAC IRSA for actual SPHEREx observations of that region.

Each image is tied to a real observation ID, detector, wavelength range, timestamp and original FITS source. Users can load matching fields across time, replay the observations, and use WCS-based exploratory image comparison. Unavailable data are shown as unavailable — never as recycled photos or imaginary discoveries.

SkyShift AI bridges research infrastructure and public understanding through bilingual access, transparent provenance, and candidate notes that require scientific verification.

**Our current status:** a functional application and locally tested API workflows, with external NASA services awaiting live validation in an internet-enabled environment. The next stage is scientifically calibrated time-domain analysis and independent judge verification of the five required targets.

**Tagline:** Watch the sky. Find what changes.
